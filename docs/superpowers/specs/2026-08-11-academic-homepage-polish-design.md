# Academic Homepage Polish Design

Date: 2026-08-11  
Repository: `Hunter-summer/yongranzhi.github.io`

## Goal

Keep the existing Academic Pages/Jekyll appearance while improving correctness, academic presentation, maintainability, and search-engine discoverability. The English-only site prioritizes publications and research outcomes as the foundation of a long-term academic identity.

## Scope

- Correct the GitHub Pages canonical URL and base path configuration.
- Replace template placeholders and incorrect account links with Yongran Zhi's profiles.
- Rewrite the homepage introduction in concise professional English.
- Keep the existing portrait, layout, and theme.
- Simplify navigation to research-relevant pages and remove the template guide.
- Improve title, description, author metadata, Open Graph metadata, and sitemap/search settings.
- Review visible publication, talk, and education entries for obvious template remnants or broken links.
- Preserve substantive academic records unless an item is clearly a template placeholder.

## Homepage Content

The homepage will identify Yongran Zhi as a Ph.D. researcher in Control Science and Engineering at Huazhong University of Science and Technology. It will foreground formation control, adaptive control, and flight control systems, with direct links to publications and verified academic profiles.

## Navigation

Primary navigation will contain Publications, Talks, Education, and CV when a valid CV page or file exists. The template Guide link will be removed.

## SEO and Publication

The project-page URL will be configured consistently as:

- `url: https://hunter-summer.github.io`
- `baseurl: /yongranzhi.github.io`

The existing `jekyll-sitemap` and `jekyll-feed` plugins will remain enabled. Canonical metadata and social-preview descriptions will use the corrected site identity. Publishing will occur through GitHub Pages after validation.

## Validation

- Build the Jekyll site when the available environment permits it.
- Check generated internal URLs and navigation.
- Verify the GitHub Pages workflow after publication.
- Confirm public access to the deployed URL and sitemap.
- Search-engine indexing is supported through standards-compliant metadata and sitemap exposure; ranking and indexing time remain controlled by search engines.

## Non-goals

- No redesign or theme replacement.
- No bilingual content.
- No fabricated publication, award, biography, or contact details.
